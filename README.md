# Nova Web CI

Site vitrine professionnel pour présenter des services de création de sites
web et d'applications à Abidjan.

## Services

- Sites vitrines
- Catalogues en ligne
- Applications web
- Maintenance
- Intégration WhatsApp
- Déploiement web

## Technologies

- HTML
- CSS
- JavaScript
